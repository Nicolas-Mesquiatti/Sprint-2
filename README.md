# 🧱 Sprint 2 - Curso de Programación Web Inicial

Este proyecto corresponde al segundo sprint del curso de Programación Web Inicial. Consiste en un conjunto de páginas estáticas construidas con **HTML y CSS**, representando distintas secciones de una web simple:

### 📄 Páginas desarrolladas:
- `contacto.html` - Página de contacto
- `nosotros.html` - Información sobre la organización
- `servicios.html` - Servicios ofrecidos
- `ubicacion.html` - Ubicación física
- Estilos individuales por sección (`.css`) y estilos generales en `styles/style.css`

### 🎯 Objetivo del Sprint
Aprender a:
- Organizar estructuras HTML semánticas
- Aplicar estilos con CSS
- Utilizar múltiples hojas de estilo
- Crear sitios navegables y accesibles
